# Copyright and Access Policy

## 论文

- Git中保存元数据、DOI、BibTeX、合法开放链接、自己的摘要与证据笔记；
- 不提交学校订阅下载的付费PDF；
- 不提交来源不明或未授权全文；
- 合法OA全文也默认由Zotero管理，避免仓库膨胀；
- 引用短句必须标明页码且遵守合理引用范围。

## 数据

- 下载前记录许可证、数据使用条款、隐私限制和派生数据发布条件；
- 原始数据默认不进Git；
- 对敏感/受限数据只保存schema、获取说明、checksum和本地路径占位；
- 公布结果时检查最小聚合粒度和重新识别风险。

## 代码

- 记录第三方仓库许可证和固定commit；
- 修改第三方代码时保留版权声明；
- 不复制许可证不明的实现；
- 论文复现代码与第三方代码边界清晰。
