# Dataset Registry

`dataset_catalog.csv` 不只是下载链接，必须记录：

- 预测对象能否由字段直接构造；
- 充电结束、拔枪离站和交易结束是否能区分；
- 负荷是实测功率、交付电量还是额定功率估计；
- 时间分辨率、缺失值和插值；
- 可否构造严格时间外、站点外或城市外测试；
- 是否能识别真实可调灵活性；
- 许可是否允许训练、发布派生数据与代码。

## 建议的第一轮数据核验

1. **ACN-Data**：会话与灵活性主候选；
2. **UrbanEV**：中国大规模站级预测候选；
3. **CHARGED**：跨城市OOD与联邦学习候选；
4. **中国13站两年交易数据**：中国会话行为与时间漂移候选；
5. **EV2Gym**：完美信息价值和预测—调度闭环仿真。

任何数据集进入正式实验前，均需在 `acquisition_log.csv` 中记录版本、校验和与许可。
