日期：2026-08-27  
状态：已完成官方论文、字段说明、数据记录和代码仓库层面的用途级审计；原始文件下载、版本固定、SHA-256和样本统计尚未全部完成。

## 总体结论

没有一个公开数据集同时提供：大规模多站实测功率、逐会话到离站、部分功率轨迹、SOC、车辆请求功率、站端设定功率、排队/放弃真值以及长期运行环境。因此，数据必须按**具体预测问题**分工，而不是按“是否适合OOD”排序。

| 数据集/工具 | 主要可观测信息 | 当前最适合的问题 | 关键限制 |
|---|---|---|---|
| ACN-Data + ACN-Sim | 会话窗口、充电电流、pilot、交付电量 | 在充会话—未来到达双源滚动预测；控制标签审计；小型调度价值 | 历史功率可能受控制；场景以校园/工作场所为主 |
| DESL-EPFL Level 3 | 1 min `P/Pset/Preq/SOC`、到离站、控制标志 | 部分曲线条件化；功率共享；请求—设定—执行分离；弱标签外部验证 | 单站、两CCS插头、1,878会话 |
| 嘉兴13站交易数据 | 起止时间、电量、价格、终止原因、天气 | 弱标签曲线重构；会话行为；结束语义和零/间歇需求 | 无直接高频功率真值，灵活性窗口语义有限 |
| UrbanEV | 大规模站点/区域占用、时长、充电量代理、价格、天气、空间属性 | 站级外部验证、多变量/多分辨率研究 | 部分volume由额定功率和状态推算，不可直接称为计量功率 |
| CHARGED | 六城市统一小时级充电量、时长和上下文 | 多环境稳健性、后续迁移/联邦扩展 | 不提供逐车高频功率与会话窗口 |
| Beijing city-scale | 大规模公共交易 | 站型异质性、峰值和大样本统计 | 时间覆盖有限，字段须下载后复核 |

| RouteZero / WeTRaC | 路线、能耗、图仿真和场站模型 | 运营车队预测—调度的平行方向 | 与公共充电站功率任务不同，且部分数据为仿真 |
| CalderaCast | 新站规划工具 | 既有工程基线和规划边界 | 模型内部、导出能力和可复现性有限 |

## 当前数据路线

### Gate 1–3：双源滚动功率预测

- ACN-Data作为主数据；
- DESL-EPFL作为独立高分辨率核验；
- 严格冻结预测发布时刻，禁止使用最终持续时间、最终电量、未来SOC和未来控制信号。

### Gate 4：弱标签功率曲线重构

- 在ACN/EPFL上隐藏真实轨迹，仅保留起止时间、总电量和允许的元数据；
- 与恒定矩形、双线性、模板聚类和潜变量模型比较；
- 只有在真实计量曲线上证明可识别后，才迁移到嘉兴等交易数据。

### Gate 5：峰值/爬坡备选

- 使用真实或经核验的高频功率；
- 同时报告全曲线、峰值时刻、峰值幅值、爬坡和阈值越限；
- 不接受仅通过峰值加权损失获得的表面创新。

### 后续数据路线

- UrbanEV、CHARGED、北京及Scotland用于外部稳健性、规模扩展或多变量研究；
- OOD/跨城市只在确有必要时作为附加验证，不决定当前论文问题。

## 不允许的表述

下载并核验真实文件前，不得宣称：

- 交易/会话结束时间等于车辆物理拔枪或离场；
- ACN或EPFL的历史执行功率等于无控制需求；
- UrbanEV的所有volume均为直接计量功率；
- 总电量除以持续时间得到的矩形曲线是真实功率；
- 模拟器生成需求等同于独立真实验证；
- 公开交易天然包含未服务需求、用户放弃或排队真值；
- 留出一个城市或站点本身构成方法创新。
