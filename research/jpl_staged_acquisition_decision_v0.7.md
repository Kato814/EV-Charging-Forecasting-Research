# JPL 分阶段时间序列获取与门控决策（v0.7）

## 决策状态

- JPL 暂定为 ACN-Data 的**主开发站点**；
- Caltech 保留为后续站点级复核；
- Office001 保留为小规模、低并发外部复核；
- 当前不执行 JPL 2018-09—2021-09 全量 `/ts` 下载；
- 先用最小连续窗口完成 Gate 1–2，再决定是否扩展。

该决策不表示最终论文只使用 JPL，也不表示 JPL 已经满足正式建模全部条件。它只是在当前同窗 QA 证据下，对下载资源进行优先级排序。

## 现有证据

站点官网可下载日期范围（UTC/GMT）：

- Caltech：2018-04-25—2021-09-14；
- JPL：2018-09-05—2021-09-14。

同窗小样本 QA 中，JPL 优于 Caltech：

- 重复时间戳：JPL 1 个点、影响 0.56% 会话；Caltech 59 个点、影响 16% 会话；
- 用户输入覆盖：JPL 97.19%，Caltech 87.2%；
- 清洗后采样点保留率：JPL 98.24%，Caltech 95.04%；
- 稀疏分钟率：JPL 0.446%，Caltech 0.760%；
- 会话边界外正电流：JPL 77 点，Caltech 1,117 点；
- 起始不完整时段：JPL 约至 02:33 UTC，Caltech 约至 03:47 UTC。

全量元数据中，JPL 有 33,638 次会话，Caltech 有 31,424 次会话，样本量不存在明显劣势。

## 为什么不能随机抽取少量会话代替连续窗口

当前任务是站级日内滚动预测：

\[
P_{\tau+h}=P^{\mathrm{active}}_{\tau+h}+P^{\mathrm{arrival}}_{\tau+h}.
\]

若只随机下载单条会话，会破坏同一时刻的并发关系，无法恢复：

- 站级总功率；
- 在充会话集合；
- 未来到达会话集合；
- 峰值和爬坡；
- 预测发布时间信息边界。

因此，站级 Gate 必须使用**完整连续时间窗内的全部会话**。随机或分层抽样仅可用于单会话剩余轨迹模型，不可替代站级评估窗口。

## 数据分工

### A. 未来到达分支

全量元数据已经足够启动：

- 到达数量；
- 到达时刻；
- 持续时间；
- 交付电量；
- 用户申报需求和预计离站时间覆盖。

该分支不需要先下载全部 `/ts`。

### B. 当前在充分支

只需在若干连续窗口获取 `/ts`：

- 截至发布时间的电流/功率部分轨迹；
- pilot/控制状态；
- 剩余持续时间；
- 剩余能量与后续轨迹。

### C. 站级概率聚合

必须在完整连续窗口内保留所有会话，按统一时间网格聚合。

## 分阶段获取方案

### Stage 1：单月最小门控

首选窗口：**JPL 2019-05-01—2019-06-01（当地时间边界）**。

原因：

- 2019-05 元数据会话数为 1,645；
- 处于疫情前稳定运行阶段；
- 与已有小样本 QA 月份一致，已知字段质量较好；
- 一个月足以构造数百个 15 min 滚动发布时刻并验证 Gate 1。

用途：

1. 完成异常结构明细和清洗规则；
2. 构造站级 15 min 功率/电流轨迹；
3. 比较 M1—M4 信息阶梯；
4. 判断会话级实时状态是否具有不可替代的增量价值。

停止条件：若 M3/M4 相对 M2 无稳定增益，不再扩大 `/ts` 获取。

### Stage 2：三季节扩展

仅在 Stage 1 通过后增加三个完整月：

- 2019-02；
- 2019-08；
- 2019-11。

与 2019-05 合计形成四个季节锚点。该阶段用于：

- 检验 Gate 1 结果是否依赖单月；
- 训练会话剩余轨迹基线；
- 检验未来到达与在充分支的不确定性贡献随时域变化。

### Stage 3：正式连续区间

仅在 Gate 1 和 Gate 2 均通过后，冻结正式连续区间。优先候选：

- 2019-01—2019-12；或
- 2018-10—2020-02。

2020-03以后受疫情和恢复过程影响的月份不作为首轮主训练区间，可保留为稳健性或行为变化补充试验。

## 加速获取路径

### 路径 1：官方 API 分月获取

- 按月建立独立文件和 manifest；
- 支持断点续传、已有文件跳过和失败重试；
- 并发不超过 2 个工作线程，尊重 429/Retry-After；
- 每月完成后立即执行 QA，不等全量结束后再检查。

### 路径 2：静态镜像作为批量来源

候选镜像：`tongxin-li/ACN-Data-Static`。

其 JPL 目录包含约 27,723 个单会话压缩 CSV，字段包括：

- Charging Current (A)；
- Actual Pilot (A)；
- Voltage (V)；
- Energy Delivered (kWh)；
- Power (kW)。

使用条件：

1. 先选不少于 100 个会话，与官方 API `/ts` 对齐核验时间戳、电流、pilot 和累计电量；
2. 记录镜像 commit SHA；
3. 原始镜像不得重新分发；
4. 论文仍引用官方 ACN-Data；
5. 镜像缺少独立许可文件，必须遵守官方 ACN-Data 使用条款；
6. 静态镜像主要覆盖 2018—2020，2021数据仍需官方API。

若镜像与 API 样本一致，可优先用镜像完成 2019 年批量获取，以避免数万次 `/ts` 请求。
