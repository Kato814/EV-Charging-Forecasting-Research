# 第二轮扩展文献审查协议

## 审查目标

补充 v0.3 可能遗漏的研究空间，并优先寻找能够否定候选创新的直接先行工作。

## 检索簇

1. 厚尾、极端峰值、突变和阈值越限预测；
2. 充电站可用性、拥堵、等待、放弃和未服务需求；
3. 缺失、异常、数据腐化及可靠性降级；
4. 早期会话总能量/持续时间预测；
5. 仿真—真实迁移、数字孪生和部署导向基准；
6. 多年纵向公开数据和真实政策/资费变化。

## 证据优先级

1. 期刊/顶会官方页面；
2. PMLR、NeurIPS 等官方 proceedings；
3. 官方数据记录（Zenodo、期刊数据页）；
4. 作者官方 GitHub；
5. 预印本只进入前沿观察，不代替同行评议证据。

## 方向判断标准

每条方向必须分别评价：

- 科学问题是否独立成立；
- 最近邻是否已解决相同输出和应用；
- 真实数据是否允许识别目标变量；
- 是否能构造严格、无泄漏的部署协议；
- 方法失败时能否被证伪；
- 是否能产生平均精度之外的风险或决策价值。

## 特别防错规则

- 稀有高峰不能在数据清洗中自动视为异常；
- 交易结束时间不能未经核验解释为车辆物理离站；
- 模拟器生成的需求不能当作独立真实验证；
- 跨时间变化不能自动等同于模型可泛化的 OOD；政策、价格、容量扩张和数据口径变化必须分开标记；
- 边际区间覆盖不代表整条轨迹或峰值事件得到保证；
- 使用目标域标签的适配不能称为零样本泛化。
