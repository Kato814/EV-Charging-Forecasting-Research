# Dataset Registry

`dataset_catalog.csv` 不只是下载链接，必须记录：

- 预测对象能否由字段直接构造；
- 充电结束、拔枪离站和交易结束是否能区分；
- 负荷是实测功率、交付电量还是额定功率估计；
- 历史功率是否受pilot、setpoint、功率共享或调度策略控制；
- 时间分辨率、缺失值和插值；
- 是否能区分预测发布时已经在充的会话与未来到达会话；
- 是否适合弱标签功率曲线重构、峰值/爬坡事件或删失需求研究；
- 许可是否允许训练、发布派生数据与代码。

## 当前优先用途

1. **ACN-Data**：双源滚动功率预测主门控；具有会话窗口、测量电流和pilot信号；
2. **DESL-EPFL Level 3**：独立高分辨率门控；具有`P`、`Pset`、`Preq`、`SOC`和控制标志；
3. **中国13站两年交易数据**：弱标签功率曲线重构、会话行为和终止语义候选；
4. **UrbanEV及其他大规模站级数据**：后续站级外部验证，但须区分实测功率与额定功率推算；
5. **CHARGED**：保留为多城市/多环境稳健性数据，不再决定当前选题。

跨数据集字段能力见 `field_audit.csv`，详细用途级审计见 `audits/`。

任何数据集进入正式实验前，均需在 `acquisition_log.csv` 中记录：

- 获取日期与来源；
- 文件版本或commit；
- SHA-256；
- 许可和再分发边界；
- 样本规模、缺失率和单位；
- 目标构造规则；
- 预测发布时合法信息边界；
- 无泄漏划分；
- 控制策略和标签语义；
- 已知限制。
