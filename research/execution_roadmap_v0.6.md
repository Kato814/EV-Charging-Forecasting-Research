# 执行路线图 — v0.6

## 总体原则

先验证问题，再选择复杂模型；先建立预测闭环接口，再扩展优化和联邦学习。每一阶段均设置明确交付物与停止条件。

## Phase 0 — 数据获取、版本固定与语义审计

### 目标

确认主方向是否具备真实可用的数据基础。

### 数据优先级

1. ACN-Data：主数据；
2. DESL-EPFL Level 3：独立高分辨率核验；
3. 其他会话或交易数据：仅作为后续弱标签和扩展验证。

### 任务

- 获取数据并记录下载日期、版本、许可和原始校验值；
- 固定时区、采样间隔、站点和会话标识；
- 区分测量功率/电流、请求功率、pilot/设定功率和站级控制；
- 统计有效会话数、缺失率、控制影响比例和异常时间戳；
- 建立预测发布时刻可用字段白名单；
- 构造最小站级聚合功率并与会话求和进行一致性检查。

### 交付物

- `datasets/acquisition_log.csv` 更新；
- ACN 与 EPFL 数据卡；
- 字段语义字典；
- 时间戳/时区核验报告；
- 控制影响审计；
- 可运行的数据加载单元测试。

### 停止条件

- 无法获得真实测量功率/电流；
- 会话和站级记录无法对齐；
- 预测时刻可用字段不足以区分在充会话；
- 控制策略无法识别且严重污染目标语义。

## Phase 1 — 直接模型与实时状态价值（Gate 1）

### 目标

不使用复杂双源模型，先判断在充会话状态是否带来不可替代的增量信息。

### 滚动设置

- 更新间隔：优先 15 min；必要时保留原始 5 min；
- 预测时域：15 min、30 min、1 h、2 h、4 h；
- 所有特征在发布时间冻结；
- 时间切分，不随机打乱未来样本。

### 基线

1. seasonal persistence；
2. 线性/岭回归；
3. LightGBM 或 CatBoost；
4. TCN 或 PatchTST 类直接聚合模型；
5. 直接分位数概率模型。

### 特征阶梯

A. 历史站级功率；

B. A + 当前占用/在充数量；

C. B + 会话级摘要（已充时长、当前功率、已交付电量等聚合统计）；

D. C + 各在充会话完整部分轨迹表示。

### 指标

- MAE、RMSE、WAPE；
- Pinball Loss、CRPS；
- 区间覆盖率与宽度；
- 峰值幅值和时刻误差；
- 最大上升/下降爬坡误差；
- 站级功率上限超越概率。

### 通过条件

C/D 相对 B 在多个预测时域和多个时间片稳定改善概率评分或关键运行指标，并且增益不能由简单增加一个占用率特征复现。

## Phase 2 — 双源分解价值（Gate 2）

### 目标

验证在充会话续充和未来到达会话分开建模是否优于强直接模型。

### 最小模型

#### 在充分支

- 简单剩余时长生存模型；
- 条件功率模板或分位数回归；
- 不首先使用复杂生成模型。

#### 到达分支

- Poisson/负二项计数；
- 到达时刻分布；
- 条件持续时间、需求电量和功率等级分布。

#### 聚合

- Monte Carlo 场景；
- 独立聚合作为起点；
- 使用共享日历/天气隐变量的相关聚合作为增强。

### 消融

1. 强直接聚合概率模型；
2. 在充分支 only；
3. 未来到达分支 only；
4. 独立双源聚合；
5. 相关双源聚合；
6. oracle 在充分支；
7. oracle 到达分支；
8. 双 oracle 上限。

### 通过条件

完整双源方法同时改善：

- 一个严格概率评分；
- 一个峰值/爬坡/超限运行指标；
- 一个来源别误差归因结果；

且不能被“直接模型 + 少量实时特征”追平。

## Phase 3 — 正式概率模型选择与强化

只有 Phase 1–2 通过后，才根据瓶颈选择模型：

- 剩余时长瓶颈：神经生存模型；
- 部分功率轨迹瓶颈：TCN、状态空间模型或 Transformer；
- 到达事件瓶颈：标记点过程；
- 属性相关性瓶颈：Copula、混合密度或 Normalizing Flow；
- 联合场景质量瓶颈：深度集成、条件生成或扩散模型；
- 场景校准瓶颈：后处理校准或保形方法。

不得因追求新颖性而同时堆叠全部组件。

## Phase 4 — 小型预测—调度价值闭环（Gate 3）

### 首选弱闭环

将 EV 基准功率场景视为外生随机负荷，优化：

- 站级功率上限；
- 变压器备用；
- 可选光伏/储能协调；
- 日内购电计划。

### 比较

1. 无预测安全规则；
2. 点预测；
3. 直接概率预测；
4. 双源概率场景；
5. 完美信息；
6. 故意失准场景。

### 指标

- 成本；
- 峰值；
- 越限率；
- 尾部风险；
- 预测场景相对 oracle 的调度遗憾。

### 继续条件

双源概率场景应改变至少一项运行决策，并在不显著增加保守性的条件下降低越限风险或调度成本。

## Phase 5 — 强闭环和第二项研究

在预测论文主线成立后，扩展会话需求场景，直接优化车辆/会话充电功率：

- 剩余需求和离站风险；
- 未来到达会话；
- 站内容量；
- 光储充协同；
- 风险感知滚动 MPC。

该阶段可以形成独立的调度研究，不与第一项预测研究强行合并。

## Phase 6 — 项目级可信分布式扩展

在中央式模型和闭环稳定后，再讨论：

- 不同运营主体数据不出域；
- 异构本地模型；
- 共享预测分布、教师输出或低维原型；
- 客户端数据质量和异常更新；
- 联邦概率校准；
- 预测可信度向调度传递。

## 当前最近动作

1. 完成 ACN 数据获取和许可/字段审计；
2. 完成 EPFL 数据访问可行性和字段核验；
3. 建立统一滚动样本构造器；
4. 运行 Phase 1 的 A–D 特征阶梯；
5. 在结果明确前不开发点过程、扩散模型或可微优化。
