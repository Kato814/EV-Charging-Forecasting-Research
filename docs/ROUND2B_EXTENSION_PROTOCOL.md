# 第二轮扩展审查协议（Round 2B）

> 版本：v0.4.0-round2-extension  
> 日期：2026-08-27

## 1. 目的

在第二轮 OOD、校准、冷启动、潜在需求、调度和联邦审查基础上，继续验证是否存在更具辨识度的科学问题，重点避免把“模型替换”误当成创新。

## 2. 扩展检索域

1. 决策诱导分布变化与 performative prediction；
2. 价格、托管充电和容量电价的随机/自然现场试验；
3. 新站建设引起的网络结构变化与需求再分配；
4. 逆向优化、偏好反演与可行域识别；
5. 排队、故障、拒绝、离队和站间替代造成的服务删失；
6. 重型卡车、公交车的路线/时刻表约束充电需求；
7. 行为异质性导致的峰值和尾部电网风险。

## 3. 纳入规则

- 优先正式同行评议论文、官方数据记录和官方代码库；
- 预印本与工作论文单独进入 `frontier_watchlist.csv`；
- 只有明确建模“行动改变后续分布”的工作才计入 performative 证据；
- 只有明确观测或建模排队/服务能力/流失机制的工作才计入服务可实现需求；
- 每条方向必须给出最近邻压力、数据可识别性、最小证伪实验和停止条件。

## 4. 排除规则

- 仅把价格作为普通外生特征；
- 仅使用 Transformer/GNN/扩散模型替换骨干；
- 仅进行静态站点留出，不考虑新站引起的网络再分配；
- 仅对峰值增加权重而无尾部概率或电网后果；
- 仅用仿真器生成结果而不审计行为反馈模型的失配风险。

## 5. 证据深度

`official abstract < publisher preview < author/publisher full text < full reproducibility audit`。当前大多数新增条目仍处于前三个层级，不能据此直接宣称文献空白。
