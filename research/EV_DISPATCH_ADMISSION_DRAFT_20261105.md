# EV 可见信息与功率适配器准入草案

日期：2026-11-05。**设计稿；未实现、未执行；所有新接口名称、判据和配置可调整。** 依据见 [字段审计](EV_POWER_FIELD_AUDIT_20261105.md)；机器可读候选字典见 [CSV](ev_dispatch_field_map_20261105.csv)。这两个文件都不是现有代码读取的授权白名单。

## 1. 三种用途分别记录

| 候选 profile | 可声明的结果 | 不能据此声明 |
| --- | --- | --- |
| `archive_current` | 按既有冻结规则进行归档电流分析；保持 A/Ah 与既有 coverage 语义 | 真实 kW、SOC、实时可得性或可调度需求 |
| `assumed_power_simulation` | 在显式电压/PF/设备/时间假设下进行人工或另行授权的仿真 | 电表级标定、真实控制收益或默认开放科研数据 |
| `measured_power_candidate` | 仅在计量、时间、版本、覆盖和身份门通过后，讨论相应边界内的实测功率 | 未覆盖设备/年份的推广；源码默认电压不能充当门通过证据 |

当前只确认字段语义和人工工程链路；真实数据接入门均未在本轮通过。实际控制器输入和仿真环境/评价真值使用两个独立结构；在线视图不接收最终离站、完成充电时刻、最终交付量或事后拟合电池状态。不要直接给控制器完整 ACN `EV` 对象。

计量依据与可得性依据须分开记录：`power_basis` 可为 measured / assumed_proxy / current_only，`availability_basis` 可为 recorded_reception / assumed_replay / unknown。真实电表归档可以保留 measured 的物理属性，同时将回放可得性标为 assumed_replay；这仍不能证明真实在线部署。上述 profile 是用途标签，不把“未证明实时收到”等同于“电表值不真实”。

## 2. 拟议准入门

| 门 | 必须记录或验证的内容 | 当前状态／不满足时处理 |
| --- | --- | --- |
| G1 来源版本 | 数据版本、字段字典、许可、获取方式、适用站点/年月、文件身份；原始值和转换留痕 | 实际样本未审计；不得把不同导出格式自动拼接 |
| G2 可用时间 | `event_time` 与有独立依据的 `available_at` 均不晚于 issue；修订、迟到、时区和陈旧度规则 | 归档只有事件时间时，保留 unknown；允许另行声明回放延迟假设，但不可称实测实时接收 |
| G3 区间与覆盖 | `interval_start/end`、instant/interval_mean/integral、积分方式、覆盖分母、缺测标记及最大保持时间 | 旧口径原样；不足以支持功率积分的区间不补零冒充完整观察 |
| G4 电气计量 | 同点实测 Power 优先；或同点同窗 V/I/真实 PF、AC/DC、单/三相、电表位置与不确定性；假设另标 | `e208_authorized` 仍为 false；假设功率不能被导出为 measured_power |
| G5 身份与容量 | `siteID/clusterID/stationID/spaceID/topology_label/node_id` 及有效期；设备型号、非零 pilot 集合、真实容量来源 | 未知映射拒绝；不将字符串相同、模型默认值或 pilot 最小值当真实电流下限 |
| G6 声明与需求 | 截至 issue 可用的修订、来源、请求总量/剩余量定义；已交付量必须是截至 issue 的同单位测量 | 语义不明时不得做剩余能量减法；声明离站过期或服务不可行须显式报状态 |
| G7 控制与真值隔离 | pilot命令、已收到/生效命令、执行电流/功率、事后评价真值分别保存；连接集合由已收到事件更新 | 禁止按未来最终能量或完成时间筛选在线对象；完整会话转换仅入隔离环境层 |
| G8 预测支撑 | 每步区间、单位、预测生成时刻、情景权重及时间依赖；完整16步只是候选形状 | 五个末端区间目标不自动通过此门；插值结果不能冒称新增验证证据 |
| G9 科研权限 | 关联明确的新输入/实验协议；旧 station-only 和月份白名单不变，holdout独立授权 | 元数据审计或工程 PASS 不解锁数据、训练或最终保留集 |

G1–G9 是本草案的设计检查项，不替代仓库已有 Gate 编号与科学判据；数值验收阈值未冻结。

## 3. 候选记录结构及决策规则

每条观测建议包含：来源版本与来源类型、字段/设备身份、值/单位/物理量种类、事件时间、可用时间及其依据、区间边界、质量/覆盖、变换链和 profile。字段缺失是状态，不是数值零。

`available_at` 只能来自可追溯接收/提交记录，或在仿真 profile 中明确标注的回放假设。由 `event_time` 原样复制的时间戳不能升级为已验证接收时间。若来源仅为历史归档，在真实在线准入视图中保持不可判定。

用户声明选择须先过滤在 issue 时已经可用的修订，再按明确修订序列消歧；不直接取完整列表最后一条。原清洗按 `(modifiedAt, raw ordinal)` 排序的行为保持不变，新适配器应另行定义并记录同时间冲突规则。

如果请求明确指总目标，且截至 issue 的交付电量确实同边界可得，才讨论 `remaining=max(target−delivered_so_far,0)`；若声明指追加量，则需要该次修订的交付基点。含义不明时返回 `UNKNOWN_REQUEST_BASIS`，不默认减 Ah、不用最终 kWh 补齐，也不从最终会话能量拟合在线初始 SOC。

连接集合由截至 issue 已收到的连接/断开事件维护。迟到断开会造成可见状态与最终真实状态暂时不同，应记录陈旧度和风险；不能用未来的最终 disconnect 修正当时视图。离线评价可以持有真实状态，但不得返回给控制器。

推荐失败/阻断状态包括 `UNKNOWN_AVAILABILITY`、`UNIT_MISMATCH`、`UNKNOWN_DEVICE_MAPPING`、`UNKNOWN_REQUEST_BASIS`、`INCOMPLETE_INTERVAL`、`INSUFFICIENT_FORECAST_SUPPORT`。名字是草案，不是已经实现的错误码；阻断时不得静默降级为“真实功率已接入”。
