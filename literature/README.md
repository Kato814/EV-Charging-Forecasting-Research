# Literature Library

## 三层证据结构

| 文件 | 内容 | 能否直接作为定稿证据 |
|---|---|---|
| `core_library.csv` | 正式同行评议论文、正式数据论文、正式仿真器论文 | 可以，但必须达到全文审读深度 |
| `frontier_watchlist.csv` | 预印本、工作论文、极新方向 | 不可以单独支撑结论；用于监测竞争路线 |
| `method_foundations.csv` | 非EV专属的算法基础 | 可支撑方法设计，但需补EV任务验证 |

## 状态字段

- `metadata-check`：只核对了题名、年份、期刊/会议和标识符；
- `to-read-full`：摘要与元数据已核验，等待全文；
- `reading`：正在全文审读；
- `reviewed-full`：全文已按模板完成证据提取；
- `watchlist`：仅持续观察，不进入主证据链。

## 证据等级

- **A**：高相关正式同行评议研究、正式数据/仿真器论文或关键基准；
- **B**：正式同行评议但相关度、评价力度或任务匹配度次一级；
- **C**：预印本、工作论文或尚未独立复核的前沿材料。

证据等级不是期刊分区，也不替代全文质量评价。
