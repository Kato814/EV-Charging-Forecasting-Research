# 最小门控实验计划 v0.4

> **历史版本提示：** 本文件记录Round 2/2B当时的方向判断。自`v0.5.0-problem-gap-review`起，OOD/未见城市/未见站点仅作为可选验证，不再作为当前论文核心。当前决策以`research/decision_recommendation_v0.5.md`为准。

## Gate S — 网络扩建与结构 OOD

### 数据
- CHARGED：leave-one-city-out；
- UrbanEV：留站、留区域、留站型；
- 半合成干预：新增节点、增容、改变价格/服务水平，并按选择模型重新分配部分需求。

### 基线
- seasonal naive / GBDT / TimeXer；
- 全局模型与普通迁移；
- 类比站 kNN/原型回归；
- 现有 OOD 时间序列方法；
- 不带拒绝的模型。

### 判据
1. 静态新站留出与结构干预留出是否产生显著不同的失败模式；
2. 支持分数与误差、覆盖缺口、峰值漏报的相关性；
3. 在固定覆盖率下，选择性预测是否降低最坏域风险；
4. 拒绝后安全基线是否优于强制外推。

### 停止条件
若结构干预与普通留站结果无实质差异，或支持分数不能预测失败，则不继续开发复杂模型。

## Gate F — 运营车队场站

### 数据
- WeTRaC：路线/城市/运营条件留出；
- RouteZero：GTFS、天气、路线能耗和场站优化；
- 扰动：延误、临时取消、额外任务、极端天气、车辆不可用。

### 基线
- 确定性路线能耗 + 固定返回时间；
- 分位数/混合密度能耗与返回时间；
- WeTRaC 官方模型；
- 确定性 LP、场景随机优化和保守鲁棒优化。

### 判据
- 能耗/返回时间校准；
- 场站整轨迹 CRPS/覆盖；
- 峰值、备用容量、未完成班次、调度遗憾；
- 相对完美信息价值保留率。

### 停止条件
若完美信息相对确定性基线几乎没有调度价值，或公开数据无法构造可信运营扰动，则停止。

## Gate P — performative 反馈

### 第一步：响应可识别性
利用公开现场试验报告的价格弹性/峰值变化作为外部校准目标，构建最小用户选择或队列仿真。验证不同响应模型是否都能解释同一观测。

### 第二步：闭环失效
比较：
1. 固定预测器 + 固定策略；
2. 每轮重训但忽略行动反馈；
3. 显式响应映射；
4. 响应映射鲁棒化。

### 判据
- 闭环稳定性与收敛；
- performative risk；
- 变压器峰值/用户成本；
- 反馈模型失配敏感性。

### 停止条件
若结果完全由预设响应函数决定，且无真实干预数据或外部效应约束，则不形成主论文。

## Gate C — 服务过程数据扫描

只审计，不训练：是否存在排队长度、等待时间、拒绝/离队、故障、端口可用性、转移站点或自然扩容事件。没有至少一种可信识别信号即停止 D3-C。
