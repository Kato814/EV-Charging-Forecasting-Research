## 1. 暂定题目与研究边界

暂定题目：**面向配电网协同优化运行的电动汽车充电负荷预测与多资源灵活性建模研究**。

| 项目 | 当前工作设想（均可调整） |
| --- | --- |
| 核心对象 | EV 充电负荷预测及其不确定性向灵活性建模、配电网运行决策的传递 |
| 辅助柔性资源 | 后续选择一种：商业建筑 HVAC 或工业负荷；依据合法数据可得性、可控性证据、与 EV 的互补性及研究价值决定，不预先指定胜者 |
| 储能 | 可选支撑资源；仅在数据/参数可解释且有增量价值时纳入，不作为必需的第二主线 |
| 网络与尺度 | 暂以 IEEE 33-bus 等辐射状配电网为候选；节点映射、容量、负荷比例及边界条件另行记录，仿真映射不等于真实同址系统 |
| 时间与运行 | 暂以 15 min 为步长、4 h（16 步）为初始日内滚动优化时域；每步更新预测和状态，仅执行首步；精确时域及终端处理在新协议中确定 |
| 范围控制 | 先建立可解释的集中式预测—运行评价链；联邦学习、复杂端到端方法和 V2G 均不自动纳入核心 |

论文拟回答：在可用信息与服务约束一致的条件下，EV 概率预测和一种辅助资源的灵活性，能否改善配电网运行成本、约束满足和用户服务；何时预测精度改进不能转化为运行收益。

## 3. 拟议技术路线与模型模块

技术路线：数据与语义审计 → EV 概率预测/场景 → EV 与辅助资源可行域 → 网络约束滚动优化 → 首步执行与状态更新 → 预测及运行价值评价。以下仅列候选模型结构，具体公式、参数、约束处理和求解器须另立协议。

### 3.1 预测与决策接口

- 在发布时间可用信息下构造 EV 概率预测：点预测、分位数/区间及带权时间相关轨迹场景；场景生成、数量、校准与削减方法均待选。仅有逐时独立分位数，不等于已经得到联合轨迹场景。
- 若 EV 作为外生负荷，输入基准策略下的负荷场景，仅调度其他资源；若直接优化 EV 充电功率，则输入会话需求、连接窗口和功率约束场景，由优化器决定充电功率。同一 EV 功率不能同时是固定负荷与自由决策变量。
- 历史策略下的执行电流/功率不自动等于未受控需求。进入 kW/kWh 网络与能量模型前，须审计电压、相别、功率因数、测量/控制语义及单位转换；条件不足时保留 A 单位结论，并明确仿真假设及适用范围。
- 未来到达、实际离站、最终电量等事后字段不得作为在线输入。现行 station-only 模型的推理信息边界保持不变；未来调度会话信息另行审计可得性，不因本框架扩大旧模型输入权限。

### 3.2 灵活性与网络约束

| 模块 | 拟考虑的约束（具体数学形式待定） |
| --- | --- |
| EV | 会话连接/可用时窗，桩及站级充电功率上下限，能量或 SOC 递推，效率，离站需求满足及未满足电量；未来到达/离站不确定性通过合法场景表达；越过滚动窗口的需求采用经验证的终端可行性处理 |
| 商业建筑 HVAC 候选 | 热状态动态、室内舒适温度区间、设备功率/爬坡限制、占用与天气条件；无温度/控制证据时不得把普通建筑负荷直接认作已辨识 HVAC 灵活性 |
| 工业负荷候选 | 可移位/可削减功率、生产时间窗、最低运行或连续运行要求、产量/能量守恒、恢复负荷及补偿；由具体工艺数据决定，不凭负荷曲线虚构可控能力 |
| 可选储能 | 充放电功率、效率、SOC 动态与上下限、终端 SOC 及避免非物理同时充放电的处理；寿命/退化参数另行说明 |
| 辐射状网络 | 节点有功/无功平衡、支路电压降、电压上下限、线路电流或容量限制、变压器/购电边界；线性化 DistFlow 或 SOCP 均为候选，需检查近似误差或松弛间隙及物理可行性 |

概率场景下首步决策须满足非预见性；后续补救决策不得提前获知真实未来。不可行场景、风险约束、服务松弛及安全回退需在实施前明确定义，惩罚项不能替代必要的物理约束。

### 3.3 候选目标函数

可用下式表达成本构成，而非已冻结的优化公式：

`min J = E_s[C_购电 + C_网损 + C_EV + C_辅助资源 + C_储能] + λ_r R_s`。

其中 EV 项可含服务不足/延迟或补偿，辅助资源项可含舒适度/生产偏离与补偿，储能项可含退化，风险项可选 CVaR 或其他尾部损失度量。无储能时省去对应项。购电结算、网损计价、风险损失定义、权重和单位需一致，避免网损及服务损失重复计费；不预设某求解器或风险模型必然最优。

## 4. 拟议评价与创新候选

- **预测评价：** MAE/RMSE、分位数损失或 CRPS、区间覆盖与宽度、峰值/爬坡误差、联合场景质量；按时距、月份和可解释工况报告，保留原单位和样本边界。
- **运行评价：** 购电及总成本、网损、峰值、电压/线路越限次数、幅度与持续时间、EV 未满足电量/按时服务率、辅助资源舒适度或生产偏离、可选储能吞吐/退化、尾部风险、求解时间与可行率。
- **拟议对照：** 无协调/固定规则、点预测、概率预测；EV 单资源与 EV 加一种辅助资源；有/无可选储能；必要的网络约束与场景校准消融。完美信息仅作离线上限参照，不作可部署输入。各对照使用同一允许评价样本、资源预算和服务要求。
- **证据边界：** 采用适合滚动重叠样本的日块等统计方法，不把重复 origin-horizon 当独立样本；新实验阈值、预算、对照、统计与停止规则均需事前确定。仿真运行收益不自动证明真实部署有效，预测更准不必然带来更优运行。

拟探索的创新候选是：（1）EV 不确定性与可执行灵活性边界的衔接；（2）EV 与单一辅助资源在网络约束下的互补价值；（3）解释预测质量何时转化为成本、风险与服务收益。**这些是待验证问题，不是已成立或已冻结的创新点。** 需结合近邻文献和消融证据判断；简单模型拼接、加入储能或更换求解器不自动构成创新。
