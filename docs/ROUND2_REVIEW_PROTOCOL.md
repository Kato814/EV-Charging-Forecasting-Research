# 第二轮文献审查协议

## 目的

第一轮发现 EV 充电预测的直接邻域已经覆盖大量模型、概率预测、灵活性和调度组合。第二轮采用“问题反推方法”的检索策略，搜索能够否定或收窄候选创新的相邻方法文献。

## 检索簇

1. OOD time-series forecasting / invariant learning / environment inference；
2. conformal prediction / covariate shift / support overlap / selective prediction；
3. zero-shot / few-shot / in-context / retrieval-augmented TSF；
4. censored demand / queue / blocked demand / abandonment / competition；
5. decision-focused / learning-augmented scheduling / prediction in the loop；
6. causal charging response / dynamic incentive / policy shift；
7. federated heterogeneous TSF / joint shift / privacy attack。

## 来源优先级

1. 期刊和顶会官方页面、PMLR、NeurIPS/ICLR proceedings；
2. DOI 出版商页面和机构知识库；
3. 官方 GitHub 仓库；
4. 预印本仅进入 frontier watchlist，不替代同行评议证据。

## 纳入标准

- 明确提出与候选科学问题相邻的方法；
- 能确定出版状态和主要方法；
- 对“创新已被占用”或“仍存在何种缺口”具有直接作用。

## 排除标准

- 仅换网络结构、没有问题层面的新设定；
- 只在随机划分中报告平均误差；
- 无法核验标题、来源或出版状态；
- 与 EV 预测或候选通用方法没有直接关联。

## 证据限制

本轮多数通用方法记录为官方摘要级核验。除明确标记 `full-text` 的条目外，不得将摘要级结论写成全文审查结论。任何最终题目仍需对最近邻文献完成全文逐节对比。
