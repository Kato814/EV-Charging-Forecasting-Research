# Related Code Registry

第三方代码只在 `repositories.csv` 登记，不默认复制进主仓库。

使用规则：

1. 记录许可证；
2. 固定tag/commit SHA；
3. 在独立目录克隆，或作为可选submodule；
4. 记录对原代码的所有修改；
5. 基线复现必须使用相同数据划分、预测发布时刻和输入信息；
6. 不以“代码能运行”代替方法正确性核验；
7. 对ACN、EPFL等高分辨率数据，必须区分实测功率、请求功率、设定功率和控制信号；
8. 第三方模型只作为最近邻或强基线，不因模型名称新颖而自动成为研究主线。

Round 3优先复现类别：

- 当前在充会话剩余时长/剩余曲线；
- 到达事件和bottom-up概率负荷；
- 占用—负荷联合预测；
- 峰值时刻/幅值/爬坡预测；
- 弱标签功率曲线重构；
- 控制策略条件下的执行功率。
