1. 大规模公共站级充电功率预测；
2. 真实车辆级可调灵活性标签；
3. 跨城市/跨年份分布外泛化；
4. 网络扩建后的真实需求再分配；
5. 排队、放弃和潜在需求真值；
6. 运营车队的车辆轮转—返回—能耗—场站功率闭环；
7. 可信联邦学习；

## 当前数据路线

### Gate S：结构 OOD

- CHARGED：跨城市主验证；
- UrbanEV：站点、区域、站型与高时间分辨率验证；
- Scotland/Beijing：外部时间/网络变化检查；
- 半合成网络干预仅用于机制门控，不能替代真实扩建验证。

### Gate F：运营车队场站

- WeTRaC：路线图、仿真代理和实车外部验证；
- RouteZero：公共 GTFS、路线能耗和场站 LP；
- 关键缺口：确切车辆轮转、返回事件、延误和真实场站计量功率。

### Gate P：决策诱导反馈

公开现场试验可提供效应范围，但微观干预数据通常不可直接获得。仿真响应必须由外部证据约束并进行失配压力测试。

### Gate C：服务可实现负荷

只有在获得排队长度、等待时间、拒绝/离队、故障、端口可用性、替代站点或自然扩容事件时启动。否则只允许部分识别或模拟门控。

## 不允许的表述

下载并核验真实文件前，不得宣称：

- UrbanEV、CHARGED、Scotland 或 WeTRaC 提供完整逐车 SOC—离站—需求电量—车辆轮转约束；
- 交易/会话结束时间等于车辆物理拔枪或离场；
- ACN 历史功率等于无控制充电基线；
- 模拟器生成需求等同于独立真实验证；
- 公开交易天然包含未服务需求或用户放弃真值；
- 新增站点的需求可通过独立插值获得，而不影响既有网络；
- 资费、容量扩张和数据采集变化都可统一解释为“行为漂移”。
