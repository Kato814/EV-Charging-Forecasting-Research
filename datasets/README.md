# Dataset Registry

`dataset_catalog.csv` 不只是下载链接，必须记录：

- 预测对象能否由字段直接构造；
- 充电结束、拔枪离站和交易结束是否能区分；
- 负荷是实测功率、交付电量还是额定功率估计；
- 时间分辨率、缺失值和插值；
- 可否构造严格时间外、站点外或城市外测试；
- 是否能识别真实可调灵活性或供给删失；
- 许可是否允许训练、发布派生数据与代码。

## 当前优先用途

1. **CHARGED**：跨城市 OOD、零/无标签/少样本冷启动和后续联邦模拟；
2. **UrbanEV**：中国城市内部站点外、区域外、时间外预测及支持域分析；
3. **ACN-Data + ACN-Sim**：预测—调度完美信息价值和鲁棒调度；
4. **中国13站两年交易数据**：会话行为、跨年漂移及结束语义核验；
5. **北京城市级交易数据**：大规模站点外验证及潜在需求可识别性候选。

跨数据集字段能力见 `field_audit.csv`，详细用途级审计见 `audits/`。

任何数据集进入正式实验前，均需在 `acquisition_log.csv` 中记录：

- 获取日期与来源；
- 文件版本或 commit；
- SHA-256；
- 许可和再分发边界；
- 样本规模、缺失率和单位；
- 目标构造规则；
- 无泄漏划分；
- 已知限制。
